# 套餐只承诺已执行的权益

## Problem

#188：Pro 灵感复制实际不限，接口与旧数据却显示 100/月。上下文窗口、独立上传次数、自定义提示词和优先支持等键没有执行路径，仍随套餐原始配置对外返回。

## Decision

保留 Pro 已有的不限制复制行为，以统一策略解析为 -1，并在后台设为只读。新默认值、合法后台保存和独立数据迁移写入 -1。公开套餐与订阅响应过滤未执行键，默认值不再生成这些键；后台仍接受已知旧键以便旧记录回存，但标为 deprecated 并在保存时排除。旧 catalog/额度字段保留兼容性零值，OpenAPI 明确标为 deprecated，不展示为权益。只清理配置表的无效键，不删除历史用量列、订阅、账本或用户数据；生产执行迁移须另行获授权，备份并回读。

## Alternatives considered

- 将 Pro 限制为 100/月能直接复用已有计数器，但会减少当前真实权益，不采用。
- 立即移除所有兼容响应字段最干净，但已缓存的客户端仍可能无条件格式化字段，可能破坏现有写作会话；保留明确废弃的中性零值，不作权益承诺。
- 实现所有历史配置项可使字段生效，但会引入未经产品授权的新限制与服务能力，本批不扩展。

## Consequences

公开有效权益、额度与执行一致；仍保留旧客户端的兼容字段及数据库历史列。管理端策略字段不能随意覆盖，其他真实权益继续可配置。没有启用灵感库、模型或新增依赖。

## Verification

7 项新增契约用例先失败，再完成相关 API/权益/seed/迁移/灵感复制 89 项和订阅/额度/测试 seed 113 项回归。后台 UI 12 项、TypeScript/完整构建、ESLint（仅既有 useAgentStream disable warning）、token/i18n 及 Ruff 通过。配置迁移还在独占本地 PostgreSQL 17.11 实际执行 Alembic upgrade/downgrade，确认真实权益、自定义字段、价格、已用次数、日月周期与订阅期限保留；不冒充生产清理证据。

降级只恢复 Pro 旧的 100 配置表示（旧执行端仍实际不限）；被删除的无效字段不捏造还原值，若需要精确原始 JSON 回滚，应使用授权变更前的已验证数据库备份。没有连接或修改生产环境，灵感开关保持关闭。
