# 官网首页的首屏比例与移动演示反馈

## Problem

在未登录访问中文官网时，1440×900 的案例图说落在首屏外；手机试玩入口只有 22px 高。移动演示区保留了四个完整案例，但滑动后没有当前位置或切换按钮。后续区块的同款大标题和留白削弱了阅读节奏。

## Decision

沿用已实现的居中标题、真实「西游记原文 → 设计规则 → 游戏」舞台、纸张与深蓝配色，不替换案例、素材、出处、双语路由或页面顺序。缩短桌面舞台和首屏间距，移除舞台的橙色光晕，统一细边框。降低二级标题与区块留白；桌面演示区使用左右分栏的导语，让案例先于解释进入视线。

手机继续使用原生横向 scroll-snap 和下一张预览。在渐进增强脚本中提供 44px 的前后按钮、当前位置、首尾禁用态；原生触摸滑动也更新位置，减少动态效果偏好下直接定位。禁用 JavaScript 时隐藏增强按钮，保留所有案例、原生滚动和视频控件。播放后的视频使用 contain，避免横屏案例被框比例裁切。

试玩、语言切换、工作台入口和搜索控件达到 44px；搜索输入使用 16px 字号，避免手机聚焦时放大。工具行的键盘聚焦使用与悬停一致的背景反馈。

## Alternatives considered

- 左文右图首屏可以突出转化入口，但会改变已确认的作品舞台布局；本次保留居中构图。
- 单纯缩小字体可以更快压缩页面，但会降低阅读和手机操作体验；主要调整舞台比例和垂直留白。
- 轮播库可以提供完整手势与分页，但现有原生滚动已经满足需求；只补反馈和按钮，不引入依赖。
- 仅保留滑动提示最简单，但不能告诉读者位置，也不能支持点击翻页；保留提示，并提供可选增强。

## Consequences

首屏完整度、触控与键盘反馈更明确；移动端案例增加一行控制栏。新增浏览器回归覆盖首屏边界、横向溢出、浅深色可访问性、按钮与原生滚动同步，以及无 JavaScript 的英文首页。静态生成器回归继续保护真实来源和内容结构。变更仅在本地验证，未发布。
