# 首作类型偏好按账号归属，公开入口意图只领取一次

## Problem

#181 的 staging 回归确认：同一浏览器先用短篇账号 A，再登出登录新连载/短剧账号 B，B 的静态首作仍是短篇。现有 `zenstory_preferred_project_type` 无账号归属；身份保存只在这个设备值为空时推断，且 `serial` 没有映射到 `novel`。

## Decision

反转 [按设备记住上次类型](../../implemented/feature/2026-10-09-dashboard-type-remembers-last-choice.md) 中设备级长期记忆的部分，不改变“明确入口选择优先于身份推断”。已认证的类型记忆使用现有 user id 的本地键；匿名公开入口使用带明确入口标记的一次性记录。匿名入口同时在 sessionStorage 的同名键保存一次性 entryId，归属当前标签页；缓存恢复、后台 /me 验证和 token refresh 只领取与本页 entryId 匹配的记录，避免 A 的后台刷新消费另一匿名标签为 B 留下的新入口。显式密码登录、邮箱验证和 OAuth 回调成功时仍可领取共享入口，保留跨标签验证回跳；领取发生在身份子树挂载前，随后消费记录。已登录访问公开入口直接写当前账号。工作台只读当前账号记忆，保留最近活动项目和 `novel` 的原有 fallback；保存身份仅在当前账号没有有效记忆时推断，补 `serial → novel`。

无法证明归属的旧设备记录不迁给新登录账号；首次认证清掉它，仍可根据该账号最近项目恢复常用类型。7 天 TTL、存储失败容错不变。没有新增选项、端点、数据库实体或依赖。

## Alternatives considered

- **只在退出时删除全局偏好。** 代码最少且能挡住本次顺序切号；但会丢掉该账号重新登录时的有效记忆，不能覆盖直接切换身份或跨标签的同类归属问题，因此使用账号键。
- **始终让身份覆盖偏好。** 连载/编剧的首次默认会正确；但会推翻刚从公开入口选择的具体作品类型，也会覆盖该账号实际创作记忆，因此保留明确选择优先。
- **把旧全局值迁给下一个登录账号。** 保留升级前的设备记忆；但这个值正可能属于已登出的 A，无法安全判定属于 B，因此只领取新版本带明确公开入口标记的记录。
- **仅在显式认证时领取匿名入口。** 能挡住后台刷新消费其他标签页，但会丢掉本页入口在 reload/会话恢复前留下的明确选择。使用同名 sessionStorage entryId 区分归属，不增加标签页注册表。
- **新增服务端资料字段。** 能跨设备稳定保存，但需要新存储合同与接口；当前账号本地键加最近项目 fallback 已覆盖本次缺陷，不扩展数据模型。

## Consequences

收益：A 的创作记忆不会决定 B 的首作目录，明确公开入口和当前账号有效记忆继续生效。成本：旧版无归属的设备记忆一次性失效；无近期项目的旧账号将回到长篇默认。验证先用真实 AuthProvider/身份边界、OnboardingPersonaPage、工作台类型 hook 与 FirstWorkEntry HTTP 客户端串起离线回归，网络和模型均合成，不产生模型费用。

## Verification

先添加实际 AuthProvider、身份边界、OnboardingPersonaPage、类型 hook 与 FirstWorkEntry HTTP 客户端的离线串联回归：短篇 A 登出后，连载 B 应初始化 novel、编剧 B 应初始化 screenplay。旧代码两条均实际提交 short，测试失败；修改后通过。另覆盖当前账号旧记忆、新公开入口覆盖当前账号旧记忆、身份不覆盖有效明确记忆、按账号 TTL/非法记录/旧记录隔离、存储不可用，以及已登录公开入口不产生可被其他账号领取的记录。

10 个受影响文件（含 AuthContext 生命周期/OAuth、App 真实认证续接、引导资料延迟读取）302 项通过；之后补的已登录公开入口案例，HomePage 12 项通过。受影响文件 ESLint 与 tsc -b 通过。模型/网络均合成，不产生真实模型费用；本提交没有推送、PR、合并、部署或线上配置操作，staging 联合验收由整合批次负责。

独立复核发现首次实现的统一 setUser 包装会让同身份后台刷新也领取匿名入口。补真实 AuthProvider 红测：A 登录短剧后，另一匿名标签写入 short，A refresh 不能改 A 记忆或消费 short；之后 B 连载仍应收到明确入口 short。旧包装实际清掉了匿名记录；现用两个独立 sessionStorage、共享 localStorage 复现标签页边界，后台只领取本标签页匹配记录，三处显式认证成功继续支持验证回跳领取。额外验证本页恢复领取、跨标签显式领取，以及 verify/OAuth 账号绑定。App 的 PublicRoute 在 loading 时显示 PageLoader，未将“加载期间点击 HomePage”当成可达路径。

归属修复后重新运行 8 个相关测试文件 253 项全部通过；受影响 5 个 TypeScript 文件 ESLint、tsc -b 和 git diff --check 通过。
