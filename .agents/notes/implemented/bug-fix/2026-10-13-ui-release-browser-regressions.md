# 发布浏览器回归修复

## Problem

main 全量 E2E 在启用可选灵感模块时发现建议文字对比度不足；英文首页与 768px 定价页有横向溢出。旧测试仍绑定旧导航角色、圆角 class、强调色明度、空官方技能展开按钮和旧占位符。工作台的手算对比度把透明背景当黑底，并以 AA 数值的 85% 命名 AAA。

## Decision

保留完整门禁和业务断言，修复实际文字颜色与布局。启用灵感建议与带工具结果的工作台扫描同时覆盖：工具状态采用已有主题化 success/warning/error 文字 token，时间戳去掉使小字不足对比度的透明度。测试定位已有语义链接、编辑器和稳定卡片标记。翻译 DOM 回归改用有公开长指令的社区技能，官方指令继续隐藏，不提供空展开。设置回归仍检查切换、存储和重载后的状态，颜色对应浅色可读强调色。使用既有 Axe 检查真实前景和祖先表面的 AA 对比度，覆盖全部可见文字，不忽略对比度违规。

局部浏览器验证启用可选模块并使用 mock API，不调用付费模型、真实支付或生产写入。局部检查通过后提交单独 PR，生产仍等待新的 exact-SHA main CI 和 E2E。

## Alternatives considered

- 回退新颜色和圆角以匹配旧断言：调整少，但撤销用户要求的改进。
- 放宽宽度、忽略对比度或跳过失败：更快，但无法发现真实问题。
- 语义与稳定入口：需调整定位，但保留业务回归保护。

## Consequences

修复实际窄屏与可选模块问题，测试不再依赖过时细节。卡片只新增定位标记，权限、保存、配额和发布门禁不变。透明颜色改用真实渲染检测，移除近似数值的误报。
