# Agent Note: 未登录主页与订阅页的布局及交互修复

## Problem

用户提供的三张截图指向工作台公开首页和订阅页。无登录态浏览 `app.zenstory.ai` 的桌面、手机整页及交互截图，确认开关圆点超出轨道、Pro 顶部色条与圆角不一致、套餐操作按钮不对齐。手机标题末尾单字换行，演示目录占用过多纵向空间、切换按钮小于 44px，自动轮播缺少暂停操作；首页祖先的 `overflow-hidden` 让 sticky 导航失效。全局未分层焦点规则还覆盖组件的 `focus-visible:outline-none`，与组件 ring 叠加。

## Decision

- 保留 React 工作台 HSL 配色与字体。焦点默认规则放入 `@layer base`，组件 ring 可以覆盖 outline，未定义 ring 的控件仍保留默认键盘轮廓。
- 首页外层改为 `overflow-x-clip`，保留页面滚动与 sticky；移动导航固定在 48px 页头下，限制高度并允许内部滚动。
- 缩小手机主标题并平衡换行；演示目录在手机排列为两列，切换按钮保持 44px、用 `aria-pressed` 标记当前场景；查看演示将焦点和滚动位置移到可命名 region。补上 main landmark。
- 轮播增加暂停/继续操作，暂停清除 interval 与待执行切换，手动选择仍可用；减少动态效果偏好下维持不轮播。
- 差异筛选用 switch/aria-checked；圆点从 left:0 定位，开关轨道与圆点尺寸明确，两个状态均在轨道内；月/年选项与筛选触控高度至少 44px。
- 套餐卡片自身裁切顶部色条，使用 1px 边框；推荐边框覆盖全局默认色。卡片为纵向 flex，桌面说明区设最小高度，操作按钮放在底部对齐。
- API 助手区域的小标签不收缩、不拆字，按钮为 44px。
- 用户继续指出差异筛选无变化：当前四项权益全部不同，加载失败时也没有可筛选内容。只在目录成功加载且至少有一项相同权益时显示开关；加载中、失败或空目录禁用购买周期与付费入口，免费注册入口保持可用。已有购买测试先等待目录加载与按钮启用。
- 浏览器 axe 实测公开页面的辅助文字、白字蓝底按钮和状态标签对比不足。公开页局部修正现有语义 token，浅色加深蓝色与辅助文字，深色蓝底使用深色文字，状态用已有 `success-text` / `warning-text`；工作台用户主题不改变。
- React 19 下浏览器里的 html lang 实际被移除，虽然 SEOHelmet 传了 htmlAttributes。由 SEOHelmet effect 按当前语言直接同步 documentElement.lang，Helmet 继续负责其他 metadata，避免两个机制同时管理 lang。
- 浏览器实点确认演示的绝对定位光晕截获切换和暂停按钮点击（修复前 Playwright 报 pointer interception）；光晕设 `pointer-events-none` / `aria-hidden`，真实鼠标点击回归验证暂停、手动切换和继续。

## Alternatives considered

- **移除所有焦点轮廓。** 最强理由是最直接消除截图里的光圈。拒绝：键盘用户需要可见焦点；修复层叠即可保留一个指示。
- **换一套主页设计。** 最强理由是统一重做可以一次调整视觉。拒绝：既有 DESIGN.md 明确保留工作台视觉，本次问题都有局部可验证的修复。
- **隐藏移动端演示。** 最强理由是显著缩短页面。拒绝：演示是首次访问理解产品的入口；缩短目录并增加阅读控制即可。

## Consequences

收益：公开页面触控、阅读与键盘导航改善，用户截图里的定位与边框问题有明确根因。代价：演示增加一个暂停按钮；焦点默认规则分层会影响所有 React 路由，因此也需验证共享 Button/PublicHeader 的现有测试。套餐与价格、额度、注册和付款后端规则保持现有合同。浏览器验证使用无登录态及合成目录响应，不发生成或付款请求。
