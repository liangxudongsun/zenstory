# 英文模板文件夹的新建类型

## Problem

核对第一篇短篇教程时发现，后端英文模板使用 Concept 和 Episode Outlines，前端共享文件夹映射缺少这两个名称。文件树的创建入口退回 draft，会把构思或分集大纲当成正文，并可能进入正文导出。

## Decision

为共享 folderTypeMap 补齐两项 outline 映射。桌面与手机文件树共用此映射；其他文件夹和已有文件类型不变。FileTreePane 回归实际在两种模板文件夹创建文件，核对请求类型和父目录。

## Alternatives considered

- 改英文模板名称：可复用已有映射，但已有项目仍保留旧名称，不能修复其新建行为。
- 在教程中要求用户绕开文件夹入口：无需改代码，但会继续把正常的大纲创建成正文。

## Consequences

英文短篇与剧本项目的新建大纲符合模板用途。既有误建文件不自动转换，避免改动用户稿件。两项回归在修复前因创建入口显示 draft 而失败，修复后运行完整文件树回归。
