# 素材深度分析

带着一个写作问题阅读参考文本，再把学到的方法用于自己的场景。分析条目帮助定位，具体原文用来验证判断。

## 选择一个问题

例如：“人物怎样改变目标，而不是突然讲一段道理？”先找到相关章节或短片段，别一次要求归纳整本书的全部优点。

把笔记分为三类：原文明示、有依据的解读、需要补读的问题。人物标签和章节摘要不能替代具体行动。

## 示例：什么改变了选择

下面是原创教学片段：

> 方遥把旧演出录音剪到第三遍，母亲的独奏仍被椅响盖住。听音会节目单写着“她最好的演奏”。朋友建议删掉杂音，接上后面重复的小节。
>
> 方遥来回播放。后面一遍快了一点。椅响之后，母亲轻声说：“别急，等他坐稳。”
>
> 方遥撤掉拼接，划掉节目单那行字，改成“那天，她停了一下”。

可以这样分析：

| 层次 | 本段依据 |
| --- | --- |
| 原文事实 | 反复剪辑、听见一句话、撤销拼接、修改节目单 |
| 解读 | 她从呈现最佳演奏，转向保留一次有意义的停顿 |
| 尚未证明 | 听众的反应、母亲的生平，以及方遥是否从此改变 |

她改变了成功标准，但杂音和被盖住的独奏还在，代价没有消失。

## 请 AI 核对你的解读

附加相关条目或引用原文，再提出问题：

```text
只分析这段原文，列出人物起初的目标、改变目标的依据、实际选择和剩余代价。
每个解读附短引文。资料不足的地方写明缺哪段上下文。
不补人物生平，不续写故事，不修改项目文件。
```

读完回复后回到原句。没有证据的判断留作问题，不直接收入自己的设定。

## 把方法变成新场景

借鉴“重新选择成功标准，同时保留代价”，可以设计完全不同的行动：

岑一只剩十分钟小车练习时间。他可以完成自己的全速练习，也可以询问第一次玩的陶陶是否想试一次左转。若他选择把时段留给陶陶，就让她自己同意、自己操作；自己的整圈练习仍未完成。

先选人物目标、选择和代价，再要求起草。不要只把录音换成录像、人名换掉，却沿用同一组事件。

```text
写岑一把剩余练习时段交给陶陶的场景。
用询问、交出控制器和等待表现变化，不写总结道理。
结尾陶陶自己完成一次左转，岑一的全速练习仍未完成。
先在对话中给候选正文，不写入文件。
```

## 保存自己的阅读成果

参考笔记记录原文位置、短引文和解读；作品提纲只放你已采用的新设计。候选正文采用后，再保存到正文文件并更新进度。
