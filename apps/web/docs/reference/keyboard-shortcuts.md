# 快捷键参考

Mac 使用 Command，Windows 和 Linux 使用 Ctrl。快捷键作用于当前获得焦点的区域，输入法确认候选时不会发送消息。

## 文件和编辑器

| 快捷键 | 功能 |
| --- | --- |
| `Command/Ctrl + K` | 打开当前项目的文件搜索 |
| 搜索中的 `↑`、`↓` | 选择结果 |
| 搜索中的 Enter / Esc | 打开结果 / 关闭搜索 |
| `Command/Ctrl + S` | 保存当前文件 |
| `Command/Ctrl + Shift + Q` | 将选区添加到对话 |
| `Command/Ctrl + Shift + R` | 对选区执行去AI味，进入改写审阅 |

撤销、重做使用浏览器文本输入的常规快捷键。保存不一定新增历史版本。

## AI 输入框

| 按键 | 功能 |
| --- | --- |
| Enter | 发送消息 |
| Shift + Enter | 换行 |
| 空输入时 Tab | 采用第一条可用建议 |
| `/` | 打开技能选择 |
| 技能菜单中的 `↑`、`↓` | 选择技能 |
| 技能菜单中的 Enter / Tab | 添加当前技能 |
| 技能菜单中的 Esc | 关闭菜单 |

技能选择后再写任务要求。手机软键盘的行为可能不同，可以使用发送按钮。

## 差异审阅

在审阅区域获得焦点时：

| 按键 | 功能 |
| --- | --- |
| `↑` / `K`、`↓` / `J` | 上一项、下一项 |
| `Y` / `N` | 接受、拒绝当前项 |
| `U` 或 `R` | 重置当前项 |
| `L` | 定位当前差异 |
| Shift + Y / Shift + N | 全部接受、全部拒绝 |
| Enter | 完成审阅 |

完成时，未拒绝的待审项会被采用。放弃候选修改时，明确选择“全部拒绝”后完成审阅。

## 不生效时

先确认焦点所在区域，以及是否处于输入法组合或审阅状态；也可点击对应按钮。当前没有自定义快捷键设置，也没有文件树的 F2 重命名或 Delete 删除快捷键。

操作说明见[编辑器](../user-guide/editor.md)和[AI 创作助手](../user-guide/ai-assistant.md)。
