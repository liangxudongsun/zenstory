# 项目管理

一个项目保存一部作品的文件、对话和项目记忆。相关人物、提纲与正文放在同一项目中，便于继续写作。

## 找到和打开项目

从工作台进入“我的项目”，按作品类型筛选，或搜索名称和描述。列表按最近更新排序；点击项目卡片打开作品。

项目页顶部的项目切换器也可搜索并切换作品。每个项目有独立地址，可以收藏；把地址发给别人不会自动授予访问权限。

## 创建和重命名

在首页选择作品类型，写下想法后点击“开始创作”。想法会作为第一条消息发送；留空则先建好项目。也可从“我的项目”的新建入口或项目切换器创建。

初始文件夹按类型区分：

| 类型 | 中文界面的初始文件夹 |
| --- | --- |
| 长篇小说 | 设定、角色、素材、大纲、正文 |
| 短篇小说 | 人物、构思、素材、正文 |
| 短剧剧本 | 角色、设定、素材、分集大纲、剧本 |

重命名时，打开项目切换器，点击编辑名称，输入后按 Enter 保存，Esc 取消。名称不能为空。

免费版最多创建 3 个项目，Pro 不限。当前用量可在[订阅权益](billing-benefits.md)查看。

## 在项目间切换

切换前确认当前文件的保存状态。不同项目的文件和对话分别保存；需要复用设定时，复制采用的内容到目标项目，并单独维护两份文件。

素材库属于账号，可以在不同项目的对话中选择相关条目。它与项目里的正文、角色文件不同。

## 删除项目

在“我的项目”卡片上点击删除，再确认项目名称与删除范围。项目切换器也提供删除入口，但会要求至少保留一个项目；需要删除最后一个时，从“我的项目”操作。

删除后，项目从可用列表中移除。目前没有面向用户的项目回收站。删除前导出正文，另存重要的人物、提纲与其他资料；项目内部的历史不能替代独立副本。
