# 使用技能

技能保存一套可复用的写作方法，例如人物塑造、场景起草或局部改稿。先选择适合任务的方法，再提供人物、原文和本轮要求。

## 添加和使用

1. 在工作台打开“技能”，浏览发现列表，按名称搜索或分类筛选。
2. 阅读名称和用途，点击“添加到我的技能”。
3. 回到项目，在输入框输入 `/` 选择技能，或从项目的技能标签添加。
4. 写清这轮要完成的任务，再发送。

一轮最多主动选择 3 个技能。AI 也会根据任务按需读取可用技能；触发词是使用线索，包含某个词不代表必定触发。

官方技能显示用途，具体指令不公开；添加后可以使用。社区技能由作者分享并经审核，公开正文可以查看。

## 管理我的技能

| 来源 | 可以做什么 |
| --- | --- |
| 自己创建 | 编辑、启用或停用、导出、分享、删除 |
| 添加的公共技能 | 使用、启用或停用、移除；可见内容由来源决定 |

已添加的官方技能不能导出正文和资源。想改变写作方法时，创建自己的技能。

## 创建自定义技能

点击新建，填写名称、用途、触发词和指令。多个触发词用英文逗号分隔。用一项具体任务开始：

```text
技能名称：有限视角检查
用途：检查人物是否知道了当前不该知道的信息。
触发词：检查视角, 有限视角

指令：先读取作者指定的人物设定和引用段落。
列出问题原句、依据和最小替换建议。
区分作者已知与人物已知，缺少依据时提问。
先给建议，不修改文件，不新增人物背景。
```

保存后，在项目中选择该技能，附上需要检查的文字。免费版可拥有 3 个自定义技能，Pro 可拥有 20 个；删除不再使用的自建技能可以腾出名额。

## 导入、导出和分享

已有技能包可从导入入口选择 Markdown 或 ZIP。导入后检查名称、指令和资源，再启用。自己的技能可导出留存。

分享会提交审核，通过后进入公共库。分享前移除私人稿件、账号信息和无权公开的文本。未通过审核不代表已公开。

详细编写、资源和格式限制见[自定义技能进阶](../advanced/skill-creation.md)。
