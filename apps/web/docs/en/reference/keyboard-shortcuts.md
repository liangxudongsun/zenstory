# Keyboard shortcuts

Use Command on Mac and Ctrl on Windows or Linux. Shortcuts apply to the focused area. Confirming an input-method candidate does not send a message.

## Files and editor

| Shortcut | Action |
| --- | --- |
| `Command/Ctrl + K` | Search files in the current project |
| `↑`, `↓` in search | Select a result |
| Enter / Esc in search | Open result / close search |
| `Command/Ctrl + S` | Save the current file |
| `Command/Ctrl + Shift + Q` | Add selected text to chat |
| `Command/Ctrl + Shift + R` | Humanize the selection and review its rewrite |

Undo and redo use the browser's normal text-input shortcuts. Saving does not always add a history version.

## AI input

| Key | Action |
| --- | --- |
| Enter | Send |
| Shift + Enter | New line |
| Tab with empty input | Adopt the first available suggestion |
| `/` | Open skill selection |
| `↑`, `↓` in the skill menu | Select a skill |
| Enter / Tab in the skill menu | Add the selected skill |
| Esc in the skill menu | Close it |

Describe the task after selecting skills. Phone keyboards may behave differently; use the send button when needed.

## Diff review

When the review area has focus:

| Key | Action |
| --- | --- |
| `↑` / `K`, `↓` / `J` | Previous, next change |
| `Y` / `N` | Accept, reject current change |
| `U` or `R` | Reset current change |
| `L` | Locate the current difference |
| Shift + Y / Shift + N | Accept all, reject all |
| Enter | Finish review |

Pending changes are adopted when you finish. To discard candidate changes, explicitly choose **Reject all**, then finish.

## When a shortcut does not work

Check focus, input-method composition, and review state, or use the corresponding button. There is no custom-shortcut setting or file-tree F2 rename / Delete shortcut.

See the [editor](../user-guide/editor.md) and [AI assistant](../user-guide/ai-assistant.md) for operations.
