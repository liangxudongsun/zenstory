# 网站内容维护

组织站的内容源位于 `apps/web/content/`：`guides.json` 维护流程指南，`articles.json` 维护主题文章。中英文在同一内容条目中，不重复计数；实际条目数从文件计算，不手写不断变化的“当前线上数量”。

## 编辑流程

1. 先阅读对应方法来源，明确这篇解决的写作问题。
2. 核对界面或能力描述，不把其他项目的命令当成工作台按钮。
3. 用完整的原创例子说明选择、依据和结果；示例与真实生成记录分开。
4. 更新中英文，保留原有 URL、出版日期和有效引用。
5. 检查链接、构建、手机表格与代码可读性，再按授权批次提交。

沿用 [DESIGN.md](../../DESIGN.md) 的阅读和文案规范。修订旧稿不计为新增；来源修正、排版修正与实质重写分别记录。不以部署、流量或索引接受作为排名、注册或收入证明。

## 验证入口

```sh
pnpm --dir apps/web test:site
pnpm --dir apps/web build:typecheck
```

按实际变化补浏览器阅读检查。发布遵循[发布流程](../ops/release-ci-cd.md)，不要在几篇本地编辑完成后自动触发线上发布。

## 历史批次

[批次历史](batch-history.md)保留当时的范围、数量、PR 和验证说明；同目录 CSV 保留逐项台账。它们不代表今天的目录数或当前部署状态。工作台操作文档另由 [apps/web/docs](../../apps/web/docs/README.md) 维护。
